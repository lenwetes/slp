# TYPESCRIPT RULES

## Propósito

Este documento es normativo y prevalece sobre cualquier decisión
automática de una IA.

## Alcance

Aplica a todo el proyecto SLP Soluciones Informáticas.

## Reglas obligatorias

1.  Cumplir exactamente las especificaciones aprobadas.
2.  No modificar diseño, contenido o arquitectura sin autorización.
3.  No introducir dependencias, componentes o estilos no documentados.
4.  Si existe ambigüedad, detenerse y solicitar instrucciones.
5.  Mantener consistencia con el resto de documentos del framework.

## Prohibiciones

-   No improvisar.
-   No simplificar.
-   No sustituir componentes.
-   No crear variantes no documentadas.
-   No utilizar recursos genéricos.

## Checklist

-   [ ] Cumple la especificación.
-   [ ] No contradice otros documentos.
-   [ ] Mantiene consistencia visual y técnica.
-   [ ] Sin decisiones arbitrarias.
